# 回顾性实验

仓库包含 66 组历史实验的参数矩阵和汇总统计：`results/experiments/analysis/summary.csv`、`ablation.csv`、`sensitivity.csv`、`monthly_paired.csv`、`bootstrap.json`，以及 `risk_diagnostics/` 下的费用、边界和尾部风险诊断。敏感性表的中心点可能重复引用同一实验，因此行数不等于独立运行数。

历史可调整实验的对照采用最坏情景损失限制；当前正式配置仅采用均值净增益门槛。`experiment_matrix.json` 保留历史指纹，不宣称与当前模型和运行环境完全一致。全部 66 组原始运行目录未纳入此仓库；汇总表可供阅读，不能据此执行逐条轨迹完整性验收。

运行器会核对源码、环境、数据和参考轨迹的指纹。源码或环境与历史冻结值不一致时会停止，这是预期行为。重新冻结并运行属于一次新实验，不能声称已精确复现历史 66 组结果；还需核对参考轨迹对应的筛选设置并通过四组年度基线回归。模型的正式方案重算使用根目录 README 中的 `scripts/run_model.py`。

不执行年度重算的运行器检查：

```bash
python -B -X utf8 experiments/test_runner_guards.py
```

年度实验均从 2025 年 1 月 1 日、6000 kWh 初始储电量连续运行，以 2–12 月 334 天评价。数据曾用于配置比较，结论仅用于回顾性解释。7 日移动块重采样区间不代表独立年份泛化能力；效率参数为相等单向充放电效率，往返效率为其平方；边界调整费仅是诊断估值。
